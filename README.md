# Fábrica Maluca do Relê

Jogos educativos de automação industrial e a Sala de Questões, tudo no mesmo lugar.

- `index.html` – portal com todos os jogos
- `games/` – Ladder, Ligações do CLP, Sensores, IHM, Partida Direta e Partida com Reversão (bancada com cabos banana)
- `questoes/` – Sala de Questões com login de aluno (nome + turma + PIN) e painel do professor (`professor.html`), usando Supabase. Veja `questoes/LEIA-ME.md`.
